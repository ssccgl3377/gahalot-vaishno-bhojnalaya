## 🏛️ About the Restaurant

Founded in **1994** in Rajasthan, India, **Gahlot Vaishno Bhojnalaya** is dedicated to authentic royal Marwari cuisine slow-cooked in unadulterated cow desi ghee. Featuring traditional wood-baked Dal Baati Churma, Ker Sangri, Shahi Govind Gatte, clay tandoor flatbreads, and dedicated 100% Jain culinary preparations without onion and garlic.

- **Official WhatsApp Hotline:** [+91 7231858636](https://wa.me/917231858636)

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/<your-username>/gahlot-vaishno-bhojnalaya.git

# Navigate to project directory
cd gahlot-vaishno-bhojnalaya

# Install dependencies
npm install

# Start local development server
npm run dev
```

Build for production:
```bash
npm run build
```
